# prozesswerk-railway

[Prozesswerk](https://github.com/guidoesser/prozesswerk) (MIT, `guidoesser/prozesswerk`): describe a business process in plain
text, get a BPMN 2.0 diagram (importable XML plus an in-browser bpmn-js editor) generated by any OpenAI-compatible LLM,
packaged as a container image for Railway.

- Upstream pinned to commit `0a6ea5a` (build arg `PROZESSWERK_REF`).
- Upstream has no authentication, and `POST /api/generate` spends your LLM key. This wrapper puts one access key in front of
  every route except `GET /api/health`: HTTP Basic (`PROZESSWERK_USERNAME`, default `admin`, with `PROZESSWERK_PASSWORD` as the
  secret), or `Authorization: Bearer <PROZESSWERK_PASSWORD>`, or `X-API-Key: <PROZESSWERK_PASSWORD>`. With none set it
  generates one for the boot and prints it in the log, so the service is never open.
- Listens on `$PORT` (default 8080) on IPv4 and IPv6, so the private network works.
- Stateless: no volume needed.

Environment: `LLM_API_KEY` (required), `LLM_BASE_URL` (default `https://api.openai.com/v1`), `LLM_MODEL` (default `gpt-4o`),
`PROZESSWERK_USERNAME`, `PROZESSWERK_PASSWORD`, `PORT`.
